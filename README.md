## Français

### Qu'est-ce que Scan Credit ?

Application pour téléphone **Android** qui facilite la saisie des codes de recharge : le téléphone lit le code de votre carte de recharge, vous n'avez plus à le taper à la main.

### Comment l'utiliser

1. Grattez doucement la carte de recharge pour faire apparaître le code.
2. Ouvrez Scan Credit et scannez le code.
3. Choisissez l'opérateur : Yas, Orange ou Airtel.
4. Appuyez sur **OK** et suivez les instructions à l'écran.

### Installation de l'application (APK)

1. Rendez-vous sur la page **[Scan Credit]([https://github.com/tianatechmadstudio/scan-credit/releases])** et téléchargez le fichier `.apk` de la dernière version.
2. Une fois le téléchargement terminé, ouvrez le fichier.
3. Si Android le demande, **autorisez l'installation depuis des sources inconnues** pour le navigateur utilisé (par exemple Chrome). Ce réglage se trouve aussi dans les *Paramètres*.
4. Appuyez sur **Installer** et attendez la fin de l'installation.

### Avertissements pouvant s'afficher

| Message | Signification et action possible |
|---|---|
| *Installer des applications inconnues* | Contrôle habituel pour tout APK ne venant pas du Play Store. Autorisez-le pour votre navigateur si vous faites confiance à la source. |
| *Ce type de fichier peut endommager votre appareil* | Avertissement classique lors du téléchargement d'un APK. Vérifiez que le fichier provient bien de la page officielle. |
| Alerte **Google Play Protect** | Peut apparaître pour une application récente non encore connue de Google. Lisez attentivement avant de choisir « Installer quand même ». |
| Demande d'autorisation **caméra** | Nécessaire pour que l'application puisse lire le code de la carte. |

> ℹ️ **À propos de la vérification des développeurs (Android) :** Google a commencé en septembre 2026 à exiger la vérification des développeurs dans quelques pays, avec une extension mondiale prévue en 2027. Si cette règle s'applique à Madagascar, la façon d'installer un APK hors Play Store pourrait changer. Consultez la documentation officielle Android Developers.

### Vérifier le fichier

La description de chaque release contient la **somme SHA-256** de l'APK. Comparez-la à celle du fichier téléchargé pour vous assurer qu'il n'a pas été modifié.

```bash
# Linux / macOS
sha256sum ScanCredit.apk

# Windows (PowerShell)
Get-FileHash ScanCredit.apk -Algorithm SHA256
```
